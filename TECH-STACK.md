# Tech Stack

- React 19 + Vite 7
- JavaScript ES modules
- Tailwind CSS 4 via `@tailwindcss/vite`
- Supabase JS client
- React Router DOM
- Lucide React
- date-fns
- Leaflet + React-Leaflet (reserved for Memory Map phase)

Versions are pinned in `package.json`. Commit the generated lockfile after running `npm install`.
