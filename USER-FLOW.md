# User Flow

## Authentication
1. Visitor opens the app.
2. Unauthenticated visitor is redirected to `/login`.
3. Visitor can sign in or switch to registration.
4. Successful authentication redirects to `/gallery`.
5. Authenticated user can sign out.

## Gallery (Phase 1 placeholder)
1. Authenticated user opens `/gallery`.
2. Empty gallery state is displayed.
3. Future phase adds upload, grid, lightbox, and couple-scoped data.
